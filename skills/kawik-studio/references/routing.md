# Optional specialist routing

Use the installed skill catalog to locate these skills. They are optional dependencies and are not bundled or overwritten by this package. Read only those relevant to the request.

| Task | Existing specialists to consult |
|---|---|
| Collaboration and initiative | `roblox-collaboration-mode` first |
| Map, prop, model, geometry | `roblox-building`; `roblox-studio-mcp` for live Studio work |
| Lighting or visual effects | `roblox-lighting`; `roblox-animation-vfx` |
| Code or module structure | `roblox-luau-core`, `roblox-luau-patterns`; types or architecture when affected |
| Remotes or exploit boundaries | `roblox-networking`, `roblox-security` |
| Player saves | `roblox-data` |
| Purchases | `roblox-monetization` |
| Cross-server state or external APIs | `roblox-server-data`, `roblox-cloud` |
| UI, controls, camera | `roblox-gui`, `roblox-input`, `roblox-camera` |
| NPCs, physics, audio | `roblox-npc-ai`, `roblox-physics`, `roblox-audio` |
| Measured performance or tools | `roblox-performance`, `roblox-tooling` |
| Design, growth, analytics, translation, release | The matching installed domain skill, when the task calls for it |

If a specialist is unavailable, use this package's relevant reference and available authoritative documentation; disclose only gaps that affect the result. Do not claim a skill was used unless it was actually read.

If an upstream RBSmithy installation is also present, select specific relevant references only when they add information. Its blanket answer templates, claims of authority over other skills, and text-only capability assumptions are not this package's process. Neither package creates tool permissions or authorizes extra side effects.
